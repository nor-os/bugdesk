## Description

In a record's children list, the points and status columns don't line up from
row to row: the status pills start at different x positions ("Refined" sits
further left than "Review"), and the assignee column is empty on some rows.

![children list alignment](/attachments/BUG-0020-alignment.png)

Cause: each `.bd-childrow` is its own CSS grid (`backlog.css:345-358`,
`grid-template-columns: 15px 78px 1fr minmax(0, 90px) auto auto`). The last two
columns are `auto`, so every row sizes them to its own content, and nothing
aligns them across rows. There is also no header row.

Fix: render the children as one table (ideally `bd_table.js` / FlexDesk
DataTable, which also gives BUG-0019 its context menu), or use fixed widths
or a subgrid so all rows share their column tracks. Text columns should be
left-aligned and numbers right-aligned.

## Comments

### 2026-10-16T06:49Z · norman_agent (status: investigation -> testing)

Fixed in 86b82cf (on main). The children list is now one CSS grid, and each
row is a subgrid of it (`grid-template-columns: subgrid`). So a column is as wide
as its widest cell in any row, and the points and status pills line up. Points
are right-aligned with tabular digits, and the pills share one left edge. A
tracker row with no due pill keeps an empty cell, so it can't shift. The DOM
test now checks the list's six columns and that rows are subgrids.

Verified in headless Edge: all three children of EPIC-0045 have their status
pill at x=1101 and their points ending at x=1093 (Draft / Refined / Draft,
13 / 5 / 8).
