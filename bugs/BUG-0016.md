## Description

Found while working on #13; not reported by anyone yet.

A product tab's breadcrumb "Governance" segment navigates to the `governance` kind with no `pane`
prop, so it always lands on the default pane (Data products), whichever category's desktop the
product was opened in. A product opened from a Lineage node, now on the Lineage desktop, sends you
to the registry inside the Lineage strip.

Expected: the breadcrumb returns to the category the product was opened from, i.e. the pane of the
desktop it lives on. `content.js` `dataProduct` → `mountTileBreadcrumb('data-product', …)`.
