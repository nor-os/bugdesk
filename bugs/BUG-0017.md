## Description

Right-clicking anywhere that has no BugDesk context menu shows the browser's (or
WebView2's) default menu: Back, Reload, Save as, Print, Inspect. In the desktop
app especially, this makes the app look like a web page and offers actions that
break it (Back, Reload).

Expected: right-click does nothing, except where BugDesk defines a menu (queue,
board and tracker rows, rail filters, tiles, tabs, desktop chips, workflow
editor, FlexDesk table headers) and in editable text (inputs, textareas,
markdown editors). There, the native menu with cut/copy/paste should stay.

Found: there is no global `contextmenu` suppression anywhere (index.html,
bootstrap, core). FlexDesk's document-level listener only hides its own menu.
A document-level `contextmenu` handler that calls `preventDefault()` unless the
target is editable or a handler already took the event would do it. That is
probably a FlexDesk feature (upstream it) with BugDesk turning it on.
