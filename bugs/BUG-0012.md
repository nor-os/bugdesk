### 2026-10-05T19:54Z · norman_agent (status: investigation -> testing)

All three are in 0a961cb.

**Deleting.** Bugs get **Delete…** on their page (beside "Mark as duplicate
and close") and in the queue's right-click menu. It asks first in FlexDesk's own
confirm dialog, then the server moves the file to a trash folder beside the
store (`.bugdesk/trash/`), so a mis-click can be undone by moving the file back.
Backlog items already had Delete, but only in tracker mode; it is now offered in
every mode, on the item page and the board's menu. That one still uses its
existing "keep or delete the children" questions.

**Closing.** **Close** is offered from Open and Investigation as well as
Testing. It still asks for the close message, like every move except Start
investigation, and that becomes the tagged comment. The help page and the
`/bugs` skill say so; an agent still closes only from testing.

**Editing a comment.** A pencil appears at the right of a comment's header when
you hover. It opens the same markdown editor in place, and Save replaces only
the text. The header — author, time and any status tag — stays as it was. The
server finds the comment by its position in the file plus the date and author
the page showed, so if the file changed underneath, it refuses rather than
writing into the wrong comment. It also refuses text containing a `## ` heading
or a `### date · author` line, because either would split the thread. This
works on bugs and backlog items.

I checked it in headless Edge on a scratch copy of this store: Close shows on
open and investigation bugs, an edit lands in the right comment with its header
unchanged, and Delete moves the file and drops the row from the queue, with no
console errors. Tests: DOM 140/140 (one new; one assertion updated because the
pencil now comes after the status tag), UI 218/218, tracker 34/34; the server
builds with 0 warnings.

To test: **restart your server**, because two of the endpoints are new. Then:
- Close an open bug.
- Edit one of your comments, and an agent's.
- Delete a throwaway bug, check it is in `.bugdesk/trash/`, and move it back.
