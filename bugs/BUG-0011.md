### 2026-10-05T19:58Z · norman_agent (status: investigation -> testing)

All three points are in 122d418, on both the bug page and the backlog item page.

**Custom dropdown.** The link type ("blocks", "relates to", …) now uses the
app's own dropdown, the one Type and Phase already use, instead of the
browser's `<select>`.

**Search in the input bar.** Typing in the target field lists matching records
from both stores under it, by reference or title, up to 8. Open records come
first and closed ones follow, dimmed; the record itself is never offered. Use
↑/↓ and Enter, or click, to put its reference in the field; press Enter again
to link. A typed `#42` or `STORY-7` still works as before.

**The magnifier dialog.** Beside its existing store chips and Closed toggle, it
gains three filters: **Type** (across both stores, so a backlog task and a
Chore bug stay distinct), **Status** and **Assignee**. Each lists only the
values actually present, so no filter can offer an empty result.

Not included: the filter editor's full AND/OR expressions. The three facets
cover finding something to link to; say if you want the full editor there.

I checked it in headless Edge on a scratch copy: chose "blocks" in the new
dropdown, typed "config", got STORY-0006, pressed Enter twice, and the record
gained `blocks STORY-0006`. In the dialog, Status = Testing narrowed 18 records
to 3. No console errors. DOM 140/140, UI 218/218.
