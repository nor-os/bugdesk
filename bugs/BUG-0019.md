## Description

In a record's detail pane, the children list (`renderChildren`,
`backlog_pages.js:1255`, `.bd-children`) has no right-click menu. The board
(`backlog_pages.js:468`), the queue and the tracker rows all have one, with
open, status moves, assign and so on. Right-clicking a child row should offer
the same row menu the board offers for that record.

The children list is hand-built `div` rows, not a `bd_table.js` table. Moving
it onto `bd_table` (see BUG-0020) gives it the context-menu passthrough
(`bd_table.js:132`) for free.
