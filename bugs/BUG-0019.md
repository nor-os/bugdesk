## Description

In a record's detail pane, the children list (`renderChildren`,
`backlog_pages.js:1255`, `.bd-children`) has no right-click menu. The board
(`backlog_pages.js:468`), the queue and the tracker rows all have one, with
open, status moves, assign and so on. Right-clicking a child row should offer
the same row menu the board offers for that record.

The children list is hand-built `div` rows, not a `bd_table.js` table. Moving
it onto `bd_table` (see BUG-0020) gives it the context-menu passthrough
(`bd_table.js:132`) for free.

### 2026-10-16T06:49Z · norman_agent (status: investigation -> testing)

Fixed in 86b82cf (on main). Right-clicking a row in a record's children list
now opens the same row menu the board has, for that child: its moves and
configured actions, Open / Open in new window / Open in split right, Add child…,
Delete…, Copy reference. A move or action re-reads only the children list, so
unsaved edits to the parent record are kept.

Verified in headless Edge against a scratch server: right-click on STORY-0047
under EPIC-0045 showed Start work / Back to draft / Drop plus the open, delete
and copy entries; "Start work" moved the file to in-progress and the row
repainted as In progress.
