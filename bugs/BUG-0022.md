## Description

Seen from AI Desk phase 1b (2026-10-20): with the bugdesk checkout on `/mnt/c/Users/Norman/repos/bugdesk` (WSL, Windows drive), a record changed through BugDesk was reverted with `git checkout -- bugs/BUG-0011.md`. No event for that change arrived on `/p/<project>/api/events`, so a client listening there (AI Desk's assignment listener) never saw that the assignee had gone back. AI Desk now rescans every project every 60 s to cover it.

Likely cause: `server/StoreWatcher.cs` uses `FileSystemWatcher`, and on WSL's drvfs mounts (`/mnt/c`) inotify does not report every change, for example those made by a rename-into-place such as git's checkout. Not yet investigated in BugDesk itself.

Steps:
1. Run BugDesk in WSL on a checkout under `/mnt/c`.
2. Listen on `/p/<project>/api/events`.
3. Change a bug in the UI, then `git checkout -- bugs/BUG-NNNN.md`.
4. Expected: an event for BUG-NNNN. Actual: none; the UI shows the old value until the next full reload.

Possible fix: a periodic rescan (or a polling watcher) when the store is on a drvfs / network mount.
