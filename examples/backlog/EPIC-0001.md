## Description

Feature work should travel with the code that implements it, for the same
reason bugs already do: a plan that lives behind someone else's login is a plan
you cannot review in a diff, cannot branch, and cannot read on a plane.

This work package gets epics, stories and tasks into markdown files beside
`bugs/`, and gives them a place in the BugDesk UI good enough that nobody
misses the web app.
