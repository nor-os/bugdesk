## Description

Steps to reproduce:

1. Type anything into the search box (e.g. "invoice").
2. Wait for results to filter.
3. Clear the box with backspace or the little "x" button.

Expected: the full, unfiltered list comes back.
Actual: the last filtered result set stays on screen until you type something
else and delete it again. A page refresh also fixes it, which is a strong hint
this is a "forgot to re-run the filter on empty input" bug rather than
anything deeper.
