## Description

A user who originally signed up via SSO, then later tried to set a local
password through "Forgot password," never receives the reset email. Accounts
created directly with email/password don't have this problem.

Guessing the reset flow assumes every account has a password-auth record to
attach a reset token to, and SSO-only accounts don't have one — but haven't
confirmed that yet. Filing this now while it's fresh; will pick it up once
#7 (the login 500 on non-ASCII usernames) is off the plate, since they're in
the same area of the code and touching both at once risks a messier diff.
