## Description

Switching to dark mode works fine for the current session, but a reload (or
just reopening the app later) always comes back up in light mode. The
preference clearly isn't being persisted anywhere.

## Comments

### 2026-07-02 · reviewer

Minor, but it's the kind of thing people notice immediately and file a
complaint about, so tagging it as a papercut rather than letting it linger.

### 2026-07-09 · agent

Found it — the toggle updates an in-memory setting but never calls the
settings-persistence save function, so it's gone the moment the page
unloads. Added the missing save call and a matching read on boot. Moving to
testing.

### 2026-07-13 · reviewer

Confirmed fixed — toggled dark mode on, closed the tab, reopened, still dark.
Also checked that it survives a hard refresh, not just a soft one.

### 2026-07-15 · reviewer

Closing. Thanks for the quick turnaround on this one.
