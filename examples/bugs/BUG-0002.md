## Description

Reported by a user on the forum. Their `config.json` had a trailing comma
after the last key (valid in a lot of editors' "relaxed JSON" but not in
strict `JSON.parse`), and the app fails during startup with an unhandled
exception instead of a readable error.

No repro steps needed beyond: any config file with a trailing comma anywhere.

## Comments

### 2026-07-19 · reviewer

Got a second report of this today, same symptom. Attaching the offending
config isn't possible here (no attachment in this example) but it's just a
comma after the last property before the closing `}`.

### 2026-07-24 · agent

Root cause confirmed: config loading calls `JSON.parse` directly with no
try/catch, so a malformed file throws all the way up to the top-level error
handler, which shows a raw stack trace instead of "your config file has a
syntax error." Two things to fix: (1) wrap the parse in a try/catch and show
a proper message with the line number if we can get one, (2) consider a more
lenient parser (JSON5 or similar) so trailing commas just work, since this is
clearly common enough to hit twice in a week. Leaning toward doing both —
friendlier error either way, permissive parsing on top.
