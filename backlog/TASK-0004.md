## Description

A "not before" date is a date I set for tickets which I do not want to see before this date. 
You probably have a better name for it.

In any case - we add this as optional exemplary extension attribute (what the epic wants). We also add a demo filter, that utilizes this attribute. If I click on the filter without the parameter enabled, I get a button to the control panel to enable.

## Acceptance criteria

- [ ] Settings › Record types offers "Snooze until" as a ready-made date field (`not_before`) that one click adds to every type of a store
- [ ] A record whose "Snooze until" date is still in the future is left out of the default open views (bugs: Active; backlog: the open views) until that day, and a built-in "Snoozed" view lists exactly those records
- [ ] Clicking "Snoozed" when no type has the field shows a notice with a button that opens Settings › Record types with the field ready to add, instead of an empty list
- [ ] With no type carrying the field, nothing else changes: no column, no filter, no hidden records
