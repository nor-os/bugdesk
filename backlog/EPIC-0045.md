## Description

Each section's home (Bugs, Backlog, Tracker) opens on a dashboard, and every one
of those dashboards is an ordinary dashboard: same storage, same editor, same
tiles. Today there are two systems. The Dashboards chip opens the standard
dashboards (FlexDesk TileGrid, `flexdesk.chart` and `flexdesk.kpi` tiles, shared
ones in `.bugdesk/project.json`, personal ones in the profile's state dir). The
Tracker home is a separate, hand-built page (`tracker_pages.js`: Overdue, Due in
the next N days, People, Needs a name or a date). It can't be customised and
can't be reused elsewhere.

After this epic:

- there is no top-level Dashboards chip. Each section's left rail lists the
  personal and project dashboards that belong to it
- the Tracker home is a standard dashboard and can be customised like any other
- Bugs and Backlog get a home dashboard too, built the same way

Requested by norman on 2026-10-16.
