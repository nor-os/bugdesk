## Description

BugDesk carries local copies of FlexDesk components where FlexDesk lacked
something BugDesk needed at the time. Each copy means every fix has to be made
twice, and the copies drift apart. When this epic is done, BugDesk uses
FlexDesk's published components as they are: anything BugDesk needed is added
to FlexDesk with tests, and the copies are deleted.

## Acceptance criteria

- [ ] BugDesk carries no copy of a FlexDesk component; `ui/js/ui/components/` is empty or gone (STORY-0008, STORY-0022)
- [ ] Every feature BugDesk needed from its copies exists in a released FlexDesk version, with tests
