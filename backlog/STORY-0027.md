## Description

Linux: WebKitGTK (`libwebkit2gtk-4.1`), a PNG icon, a `.desktop` file, an AppImage or `.deb`; no handle-based window code (Photino's WindowHandle throws there). macOS: an `.app` bundle with `Info.plist` and `.icns`, signed and notarised, in a `.dmg`.

From the STORY-0009 spike; see `docs/desktop-spike.md`.
