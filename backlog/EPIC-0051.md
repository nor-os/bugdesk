## Description

AI Desk (`../aidesk`, AI Desk EPIC-0100, `../aidesk/backlog/EPIC-0100.md`) runs a stock BugDesk and shows
BugDesk's own views (bug list, ticket mask, backlog item) in its own FlexDesk tiles and managed windows, one
module instance per project. It consumes the newest BugDesk release as it is, so BugDesk must be embeddable
without forks or patches.

When this epic is done, any FlexDesk application can mount BugDesk's content kinds for a project by importing
them from that project's URL, and the contract for doing so is documented.

## Acceptance criteria

- [ ] AI Desk shows BugDesk views of two projects side by side in its own shell, running a stock BugDesk release (STORY-0052)
- [ ] The embedding contract is documented in the README and covered by a test
