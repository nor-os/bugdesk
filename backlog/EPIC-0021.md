## Description

Run BugDesk as a desktop application in a native window instead of a browser
tab, as EcoSim does with pywebview. The native capabilities belong in FlexDesk
(a host bridge any FlexDesk app can use), so EcoSim can move onto the same
bridge later. It starts with a spike (STORY-0009) to choose the host and design
the bridge; the build stories are filed from the spike's findings.
